# Карта сайта АНО «Цифровая экономика»

Схема страниц нового сайта: из каких блоков состоит каждая страница и куда из блока можно попасть.

Откройте `index.html` в браузере.

## Обозначения
- **↓** — блок ведёт на страницу ниже по дереву (линия на схеме)
- **→ Страница** — переход в другую ветку (кликабельно)
- **↗** — внешний сайт или файл
- **▣** — ссылка на скриншот-референс
- **●** (красный) — под вопросом
